# Архитектура

Electron main управляет окном, треем, разрешёнными IPC, файловыми диалогами, clipboard и SSO. Renderer — React/Vite, Tailwind/shadcn, TanStack Table и Virtual. Node API недоступны renderer: sandbox + contextIsolation, один узкий preload bridge, Zod-discriminated union без произвольных URL/SQL/path.

Движок и единственный постоянный SQLite writer находятся в worker_threads. Это сознательный эквивалент utilityProcess из ТЗ; тяжёлый пересчёт не выполняется на потоке React. SQLite работает с WAL/FK, миграциями и Drizzle для настроек; транзакционные доменные операции используют prepared statements better-sqlite3. Миграция существующей базы предварительно создаёт VACUUM INTO копию. Базы DEMO и портфеля разделены.

## Границы

- engine/accounting: Decimal, FIFO, сверка, распределение сумм и подтверждений.
- engine/portfolio: согласованный бюджет, профили навыков/standing, резервирование и сделки.
- engine/market: SDE, полные поколения ордеров, расчёт кандидатов и быстрые фильтры.
- engine/history + liquidity: доступная региональная история и объяснимые правила.
- engine/routes: обычные врата, BFS зоны, security modes, дополнительные остановки.
- engine/esi: кеш, ETag/304, Retry-After, очередь, ограниченная конкурентность.
- engine/background: уведомления, retention и экспорт.
- desktop: OAuth PKCE в системном браузере, одноразовый loopback state, safeStorage; refresh single-flight на персонажа.

EVE IDs — строки; API JSON разбирается lossless. Деньги — decimal.js; исчисляемые количества проверяются на безопасные целые. Timestamps — UTC. Основа продаёт все партии; покупатель не выбирается при принятии сделки.

## Данные и воспроизводимость

Каждая полная региональная загрузка атомарно публикуется после проверки страниц и общего Last-Modified. Неполная остаётся failed/interrupted. Храним две последние полные глубины региона; прежние прогнозы содержат свои исходные лестницы независимо от cache. Метаданные кеша старше 7 дней и записи наблюдений/несостоявшихся возможностей старше 90 дней очищаются. Принятые сделки, операции, партии, расходы, неизменяемые прогнозы и события не удаляются retention.

Станционные наблюдения — последний стакан за день, а не якобы исполненные сделки. History остаётся региональной. Расходы допускают явное распределение источника; сумма allocations не превышает исходную journal amount. Фактический результат версионируется result.snapshot; подтверждение полноты расходов связано с хешем текущих распределений.

Сначала строится набор кандидатов по стакану/бюджету/типовым лимитам. Изменение видимых порогов переиспользует подготовленные лестницы и пересчитывает количество, расходы и ROI, а не загружает рынок заново. Резервы уже выбранных закупок/покрывающих buy уменьшают общую доступную глубину.

## Проверки

Unit/integration без интернета; Electron E2E на отдельной userData-директории. DEMO запрещает SSO и не подменяет реальный API при ошибке. Публичный live benchmark opt-in использует сохранённый полный The Forge. Packaged smoke запускает бинарник из .app / win-unpacked, проверяет worker, SQLite, настройки, трей и restart. Подключение пользователя и реальная торговля не имитируются как live PASS.
