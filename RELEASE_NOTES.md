# EVE Trader 0.1.32 — обновление во время долгого сканирования

Исправлен повторный сбой обновления на больших базах. Перед обновлением приложение дожидается окончания синхронизации ESI, останавливает занятый рыночным расчётом движок, сохраняет активную и DEMO-базы через SQLite backup API и передаёт управление установщику. Расчёт рынка больше не блокирует создание резервной копии.

Проверка: полный локальный verify; реальное обновление установленной версии 0.1.29 будет подтверждено после выпуска.

# EVE Trader 0.1.31 — надёжный запуск встроенного обновления

Исправлена установка обновления в приложении с большим сохранённым рынком. Новая сборка сообщает updater, что окно и локальная база готовы, до полного расчёта рыночных возможностей. Долгий пересчёт больше не вызывает автоматический откат новой версии. Добавлена packaged-проверка startup handshake.

Также включены изменения 0.1.30: производственная вкладка, пакетный фоновый расчёт и исправление чтения числового `race_id` из приватного ESI.

Проверка: полный verify, упаковка и packaged smoke на macOS и Windows; приватный live-ESI sync проверен отдельно. Сверка производственных налогов, выхода переработки и профиля Upwell-структуры всё ещё требует игровых данных.

Добавлена вкладка производства: оценка производственных и перерабатывающих предложений, проекты с привязкой к заданиям и операциям кошелька, учёт навыков Alpha, глубины рынка и локальных настроек станций. Длинные расчёты рынка идут пакетами в фоне, сохраняют уже найденные предложения и показывают отдельный прогресс сканирования.

Исправлена синхронизация персонажа с приватным ESI: API отдаёт числовой `race_id`, а не строковое поле `race`. Из-за этого профиль мог падать до загрузки навыков и активов. Добавлены регрессионный тест и закрытая live-проверка чтения профиля, чертежей и заданий без игровых записей.

Проверка: полный локальный прогон — 112 unit, 38 integration и 4 desktop E2E теста; отдельно пройдены публичный live ESI, приватная синхронизация авторизованного профиля и macOS packaged live-ESI E2E. GitHub Actions собрал и проверил macOS и Windows. Производственные налоги/выход переработки и доступ к конкретной Upwell-структуре всё ещё требуют сверки с игровым клиентом; прогнозы продажи остаются оценкой, не гарантией исполнения.
