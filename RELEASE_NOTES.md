# EVE Trader 0.1.29 — перенос Ренса в существующую базу

Исправлен переход на новый справочник центров для уже установленного приложения. При запуске приложение дополняет сохранённый SDE недостающими станциями новых хабов из комплекта приложения, даже если номер сборки SDE не изменился. Это добавляет 8 станций Ренса и регион Heimatar к существующей базе, не удаляя сделки. Источник рынка виден как выбранные хабы без фиксированного числа.

Также включён NPC-рынок Ренса (Heimatar) как четвёртый торговый хаб. Хек в постоянный скан пока не добавлен: по live-срезу ESI он увеличит полную загрузку ордеров примерно на 16% поверх четырёх рынков приложения и добавит около 9 тысяч типов в фоновую очередь истории. Сначала оцениваем скорость и полезность Ренса.

Периметр: публичные региональные данные уже включают The Forge, однако они не дают основной стакан Upwell-структуры. Для просмотра такого стакана нужна отдельная авторизация ESI с `esi-markets.structure_markets.v1` и docking access персонажа к выбранной структуре; приложение пока не запрашивает этот scope.

Проверка: миграционный integration-тест воспроизводит старый SDE с тремя хабами и подтверждает автоматическое добавление Ренса при старте. `pnpm verify:all`: lint, typecheck, 40 unit, 34 integration и 3 e2e теста прошли; performance-сценарий пропущен из-за отсутствия базового набора. macOS packaged smoke и установка встроенного обновления проверяются при выпуске. macOS-сборка подписана ad-hoc; Developer ID/notarization отсутствуют.
