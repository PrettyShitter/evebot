# Stage 01 — отключение производства

Статус: **PASS для пользовательского приложения**. Производственные данные и таблицы пока сохранены в `portfolio.sqlite`; миграция архивных резервов будет отдельным безопасным этапом.

## Изменения

- Удалены вкладка, экран и рендер производства. В интерфейсе осталось ровно три торговые вкладки: рынок, текущие сделки, закрытые сделки.
- Удалены стартовая загрузка production/structure/contract ESI и 30-минутный production poll.
- Новые рыночные поколения больше не дублируют исключённые торговые типы в production-only snapshots; исключённые предметы отбрасываются при чтении страниц рынка.
- Все `state` запросы от desktop-процесса принудительно отправляются worker с `includeProduction=false`, даже если старый renderer попросил бы production summary. Состояние рынка и wallet-sync больше не запускают производственные расчёты.
- Старые production IPC-команды отклоняются в desktop main с сообщением, что раздел выключен и архив сохранён.
- Новая OAuth-авторизация продавца запрашивает только wallet, skills, skill queue, standings и character market orders. Scopes assets, blueprints, jobs, contracts и structure markets не добавляются.
- Старые таблицы, архивные проекты, транзакции, расходы и фактические значения не удалялись и не изменялись. Текущая пользовательская SQLite не открывалась на запись.
- Удалены устаревшие production live/private/packaged E2E-сценарии; добавлен E2E, который запускает приложение на временной demo-базе и проверяет торговую навигацию и отклонение старого IPC.

## Ограничения

- Production-компоненты и таблицы остаются в коде/схеме как невызываемый архивный код и данные; desktop IPC не допускает их вызов из приложения. При новом публичном UI их больше нет.
- Удаление незавершённых **плановых** production reservations с отдельным идемпотентным журналом ещё не выполнено. Оно относится к миграции портфеля на следующем этапе; выплаченные расходы и баланс не меняются.
- Не выполнялся приватный ESI smoke и не использовался реальный подключённый пользовательский портфель в тестовом окне. Эти проверки не нужны для доказательства отсутствия production sync: автозапуск удалён из единственной desktop точки запуска, а сетевые production adapters больше не имеют вызывающего клиента вне архивного worker-кода.
