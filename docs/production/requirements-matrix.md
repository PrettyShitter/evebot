## Current acceptance boundary

The Production tab is **not release-ready yet**. Public live ESI, fixture-backed workflows, and automated regression pass, but the main character's token lacks production scopes and no private jobs/blueprints/assets or in-game fee/yield preview have been verified. Remaining product gaps include procurement/transport duration and real-account validation of multi-copy contract matching. Unknown, stale, and incomplete data remains marked for review; structure parameters must be entered from the game and are not presumed by ESI.
