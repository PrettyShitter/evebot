# Этап 5 — интерфейс возможностей (частично)

Дата: 2026-10-08 (Asia/Ho_Chi_Minh). Рабочая ветка `codex/production-tab`; без commit/push.

## Реализовано

- Добавлен локальный фильтр по максимальной полной себестоимости для manufacturing и reprocessing предложений.
- Добавлен выбор сценария выхода: немедленная продажа в buy-ордера или прогноз выставления sell-ордера.
- Добавлена сортировка manufacturing по чистой прибыли, ROI или прибыли на час занятого слота. Для reprocessing слот-час не применяется и остаётся сортировка по выбранной прибыли.
- Фильтр работает только с уже рассчитанным набором и не вызывает новый ESI-расчёт. Пустой список различает отсутствие предложений и список, скрытый лимитом себестоимости.
- `pnpm test:e2e:live` теперь всегда делает свежую сборку, запускает полноценный Electron non-DEMO с изолированной базой, проверяет настоящий публичный ESI и интерактивность новых фильтров.
- Добавлено ручное количество прогонов Manufacturing с серверным пересчётом той же сметы по текущему стакану. Пересчёт проверяет максимум рынка/бюджета, материалы, выход, сборы и прибыль; неполная глубина не выдаётся за готовую сделку.
- Контракты BPC по умолчанию показываются компактным списком из пяти записей, полный список раскрывается отдельно.
- Карточка проекта показывает неизменный стартовый прогноз и отдельную текущую себестоимость: учтённые покупки по факту + только недостающие материалы по свежим sell-ордерам + фактический/ожидаемый сбор. Если глубина или сбор неизвестны, текущая сумма не подменяется нулём.
- Добавлены фильтры проектов по закреплённым, активным и завершённым; размер партии Reprocessing также можно менять и повторно проверять по целым порциям, стакану и бюджету.
- Добавлены локальные фильтры минимальной прибыли и названия предмета; они не запускают повторный ESI-расчёт.
