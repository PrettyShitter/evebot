# Этап 1 follow-up — приватные рынки структур

Дата: 2026-10-08 (Asia/Ho_Chi_Minh)
Рабочая ветка: `codex/production-tab`; изменения проверены в рабочем дереве, без commit/push.

## Изменение

- Добавлена отдельная paginated загрузка `GET /markets/structures/{structure_id}` только для вручную подтверждённых structure profiles в системах Jita/Perimeter.
- ESI-ответ не содержит `system_id`; код добавляет его из подтверждённого профиля площадки.
- Migration 007 добавляет отдельные таблицы охвата и структуры ордеров. Полный снимок заменяет прежние ордера транзакционно; 403, ошибка, отсутствующий scope или превышение лимита страниц сохраняют предыдущий снимок, но отключают его от текущего расчёта.
- UI показывает число ордеров, страницы, время, устаревший снимок, ESI 403, ошибки и недостающий scope отдельно от пустого стакана. Добавлена кнопка переподключения основы с требуемым scope.
- Private live ESI для пользовательского токена ещё не проверен. Публичный ESI и настоящая Electron-сборка проверены изолированным профилем.
