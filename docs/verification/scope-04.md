# Покрытие этапа 4

Движок индексирует ордера по type/location; географическая применимость buy кешируется отдельно. Предложения ограничены подтверждённым cash/type cap и выгодным маржинальным хвостом; два сценария рассчитываются на одном количестве. Минимальный сбор/релист и стресс -5/-10 отдельно. История региональная с явными отсутствующими днями.

Rule-based sell limit v1: min(2% медианного регионального дневного объёма ×3, локальная buy-depth либо подтверждённые локальные продажи ×3) минус конкуренты не дороже целевой цены. Нужно минимум 7 наблюдаемых/5 активных дней из 30. Target выше 125% медианы отклоняется для sell. Это консервативная модель, не вероятность. Для buy история не запрещает текущий исполнимый выход.

market.test.ts: воспроизводимость кандидатов, изменение партии/м³, лимит типа, резерв/двойное принятие/отмена, отсутствие ложной ликвидности одиночной цены. Базовые fixtures и property tests запускаются повторно. Признаки и settings на принятии сохраняются в immutable forecast.

Внешнее ограничение: данные активных навыков могут отставать от offline skillqueue. Если новый завершённый уровень ещё не отражён и нельзя доказать активность Alpha/Omega, прогноз блокируется до обновления профиля, а не подставляет неподтверждённый уровень.
