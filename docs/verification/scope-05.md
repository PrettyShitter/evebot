# Покрытие этапа 5

MarketView: TanStack Table 9 + Virtual, фильтры и пресеты, две модели на одну партию, карточка с лестницей/сборами/региональной историей/стрессами, корзина точной пары станций, plaintext английский type name + quantity для мультибая через clipboard main. Автообновление предлагает кнопку «Есть обновления», а не переставляет выбранную строку.

Playwright market.spec.ts запускает Electron, меняет минимальную прибыль до пустой выдачи и назад, меняет количество и проверяет изменившуюся закупку, принимает корзину и проверяет подтверждение. Финансовая идемпотентность двойного принятия проверена integration tests. Скриншот market-selected-1440.png. Прочие проверки shell продолжают работать на 1280×800 и zoom125%.

Совместимость формата мультибая с реальным игровым клиентом требует пользовательской проверки (BLOCKED без игровой сессии). Приложение не вводит текст в EVE автоматически.
