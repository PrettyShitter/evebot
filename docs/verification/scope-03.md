# Покрытие этапа 3

Официальный SDE загружен и нормализован в bundled справочник: версия, все системы и обычные врата, рыночные типы, NPC-станции объединения пяти прыжков, рыночные группы. static.test.ts проверяет точные центры, совпадение BFS, пересечение регионов, отсутствие дублей, исключение PLEX и packaged volume.

sync.test.ts проверяет неполную страницу/503 с сохранением предыдущей генерации, 304, cache expiry с fake clock, Retry-After, scheduler priorities/bounded retries/suspend-resume, неизвестную history без выдуманных дней. Публикация региона одной SQLite transaction, сохраняются начало/конец загрузки и Last-Modified. Прерванные runs отмечаются interrupted после restart.

SDE и station names получены live read-only. Полный market scan всех регионов ещё требует проверки длительности/памяти этапа 9. Станционные наблюдения и их роль в ликвидности добавляются с движком этапа 4. Кэш HTTP пока в памяти процесса, опубликованные снимки/история — в SQLite.
