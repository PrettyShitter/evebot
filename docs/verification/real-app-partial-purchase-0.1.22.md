# EVE Trader 0.1.22: проверка частичной покупки в реальном режиме

Проверка выполнена 2026-10-04 на упакованной macOS arm64-сборке. Приложение запущено с `EVE_DEMO=0` и `EVE_OFFLINE=1` на изолированной копии профиля EVE Trader, содержащей три подключённых персонажа и выбранную сделку. Рабочая база пользователя не изменялась.

В копию профиля добавлена тестовая личная покупка с дополнительного персонажа: 5 единиц товара для сделки, в которой выбрана 1 единица. В реальном интерфейсе приложения вызвана команда привязки покупки. Итоговое состояние: `demo=false`, три персонажа загружены, в сделку зачтена 1 единица, остаток сделки ожидает продажи, в сверке появилась партия на передачу основному персонажу. Четыре избыточные единицы в сделку не включены.

Интеграционный тест дополнительно проверяет несколько покупок с разных дополнительных персонажей, ограничение партии остатком сделки, точную себестоимость по цене транзакций и то, что продажа с дополнительного персонажа не распределяется в сделку основного персонажа.

Пакетная проверка: подпись macOS bundle валидна; приложение запустилось, открыло экран рынка, сохранило настройку и повторно запустилось с сохранённым значением.
