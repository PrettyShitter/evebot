# Покрытие этапа 1

Store integration: чистая миграция, повторное открытие, сохранение настроек, откат транзакции, ошибочная миграция, SQLite backup API/restore/integrity/FK. IPC rejects неизвестные команды, дополнительные поля, SQL/proxy/file paths.

Playwright запускает настоящий Electron на macOS arm64, переключает три вкладки, проверяет отсутствие window.require, сохраняет настройку и проверяет её после закрытия/нового процесса. Снимки 1280×800 и 1440×900 при zoom125% находятся в test-results. Page errors отсутствуют. Это начальная оболочка, функциональные рынки и сделки относятся к следующим этапам.

SQLite 13 работает в установленном Electron 44.5.1 и Node 26.5.0. Упакованный runtime пока не проверялся. Секреты в этой версии ещё не создаются. DEMO использует отдельный файл базы. Начальная миграция v1; тест обновления на будущую схему будет добавлен вместе с ней.
